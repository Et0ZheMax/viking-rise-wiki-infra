# Docker-образ и запуск Wiki.js для Viking Rise

Этот документ фиксирует, что в репозитории уже есть **рабочий docker-compose**, который собирает инфраструктуру Wiki.js и подключает все необходимые модули: базу данных, приложение Wiki.js и Nginx reverse-proxy. Ниже — что именно входит в стек и как быстро запустить сайт.

## 1. Что входит в рабочий docker-стек

Композиция построена на официальных образах и включает следующие модули:

- **PostgreSQL 15 (alpine)** — основная база данных Wiki.js.
- **Wiki.js v2** — приложение Wiki с визуальным редактором, загрузками и встроенным поиском.
- **Nginx (alpine)** — reverse-proxy, публикует HTTP-порт из `.env` и проксирует трафик на `wiki:23000`.

> Все секреты и параметры подключаются через `.env` и **не коммитятся** в репозиторий. В Git хранится только безопасный шаблон `.env.example`.

## 2. Атрибуты сайта и где они включаются

Инфраструктура запускает Wiki.js, а ключевые атрибуты сайта настраиваются через веб-интерфейс:

- **Визуальный редактор** — включён по умолчанию (раздел **Administration → Editing**).
- **Загрузка файлов и медиа** — локальное хранилище `/data/wiki/uploads` (раздел **Administration → Editing → Uploads**).
- **Поиск по статьям** — встроенный Database-движок (раздел **Administration → Search**).
- **Минималистичный интерфейс** — задаётся через **Administration → Theme**.
- **Места под рекламные баннеры** — подготовить позже через тему и шаблоны (добавить CSS/разметку в теме).

Пошаговые настройки через UI описаны в `docs/wiki-setup.md`.

## 3. Быстрый запуск (Windows / WSL / Linux)

1. **Подготовить переменные окружения**
   - Скопируйте `.env.example` → `.env` и задайте свои значения.
2. **Скачать образы и поднять сервисы**
   - `docker compose pull`
   - `docker compose up -d`
3. **Проверить готовность**
   - `docker compose ps` — убедиться, что `db`, `wiki`, `nginx` в статусе `healthy`.
   - `python scripts/health_check.py` (Linux/WSL с `sudo`) или `py scripts\health_check.py` (Windows, администратор).
4. **Открыть сайт**
   - `http://localhost:<PUBLIC_HTTP_PORT>` (порт берётся из `.env`).
5. **Первичная настройка**
   - Создайте admin-аккаунт и настройте параметры по инструкции `docs/wiki-setup.md`.

## 4. Остановка и перезапуск

- Остановить: `docker compose down`
- Перезапустить после изменений: `docker compose up -d --force-recreate`

> Если потребуется HTTPS, TLS можно терминировать во внешнем reverse-proxy (Cloudflare/Traefik) или вынести в отдельную конфигурацию Nginx.
