# Глоссарий

> Термины, которые чаще всего встречаются в гайдах по **Viking Rise (Викинг Райс)**.

---

## Основные термины
**KVK** — Kingdom vs Kingdom, массовое противостояние королевств  
**Марш** — один отряд (герои + войска), участвующий в бою  
**Лазарет** — здание для лечения раненых войск  
**Фокус** — совместная атака одной цели группой игроков  
**Синергия** — сочетание навыков героев, усиливающее результат связки
